# Mouse&Keyboard Bridge

One mouse and keyboard for your Mac and your Windows PC. Move the cursor
off the edge of one screen and it appears on the other; the keyboard and
the clipboard follow it.

- **Download:** [latest release](https://github.com/Aziksmylv/mousebridge/releases/latest)
  (macOS installer `.pkg`, Windows installer `.exe`)
- **Support:** https://aziksmylv.github.io/mousebridge/
- **Privacy Policy:** https://aziksmylv.github.io/mousebridge/privacy/
- **Report a problem:** [open an issue](https://github.com/Aziksmylv/mousebridge/issues/new)

This repository hosts the website and the release downloads.
